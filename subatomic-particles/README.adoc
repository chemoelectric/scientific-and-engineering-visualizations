= The structures of subatomic particles

_The whole universe may be pictured as one big electromagnetic field._

Within it there are these structures we know as “electrons,”
“protons,” and “neutrons.” They are dynamic entities full of swirling
electromagnetism. Nevertheless, some of the key components of these
structures may be visualized as shown in these plots.

Note that there are no “quarks” and there is no “strong force.” The
three inseparable electromagnetic toroids of the proton and neutron
were mistaken for “quarks.”

The “anti-particles” are similar, but have some dynamic properties
reversed. This reversal makes them unstable in the geometric-time
structure of the universe.
